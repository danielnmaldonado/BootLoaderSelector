BootLoaderSelector — Changelog
================================

Current version: 2.33
Author: MaLd0n / DNMTechLabs
Credits: ©DNMTechLabs / dnmtechlabs@gmail.com

This is a concise English history of the changes recorded in the received
source. Repeated audit narratives and environment-specific test counts have
been consolidated. The original documents remain in Git history and the
original source ZIP. Current instructions are in INFO.txt and README.md;
recorded validation and its limits are in VALIDATION.md.

2.33 — English project launch — 2026-11-04
-----------------------------------------
- Reorganize the project documentation into a current English reference,
  concise release history and evidence-based validation record.
- Make MaLd0n / DNMTechLabs authorship, upstream credits and license notices
  visible, with a dedicated CREDITS.md.
- Add the project's Ko-fi, PayPal, Revolut, Remitly and Mercado Pago support
  links, matching the TahoeRealtekWiFi project.
- Prepare standard release publication after the same five mandatory CI checks.
- Enforce the same five-check release gate for 2.33. The authoritative status is
  available in the version-specific Actions runs and release linked in VALIDATION.md.
  No new real-hardware or Secure Boot trust certification is claimed.

2.32 — Publication corrections — 2026-11-03
------------------------------------------
- Correct DevicePathLib format validation, USB-WWID copy/cleanup and propagation
  of allocation failures in the converter actually linked into the application.
- Verify certificate self-signatures cryptographically with their own public
  keys while retaining the leaf/codeSigning policy.
- Detect compiler and sanitizer capabilities, make publication regressions
  compatible with macOS Bash, and require the CI gates before publication.
- Bound BaseTools message concatenation under fortified GCC; rebuild deep-test
  dependencies with the selected compiler.
- Handle incomplete reads and I/O failures in GenFv/GenFw with cleanup and error
  propagation, preserving valid output formats.
- Handle Split directory/getcwd failures, restore the directory and release
  memory on error.
- Roll back release publication on cancellation; make Finder log reveal opt-in.
- Distribute the project's code under BSD-3-Clause, preserve upstream notices,
  and exclude the legacy binary toolchain while retaining its hash catalog.
- All five checks passed for the submitted main source and v2.32 tag; the tag
  release job published a prerelease. See VALIDATION.md for the run links.

2.31 — Build-log concurrency — 2026-10-10
----------------------------------------
- Emit Debug-wrapper diagnostics from Release cleanup while the build lock is
  still held, preventing a second build from truncating or mixing log content.
- Add a concurrent-build regression. UEFI runtime behavior was unchanged.

2.30 — Critical certificate extensions — 2026-10-10
--------------------------------------------------
- Require critical Basic Constraints and Key Usage extensions, matching the
  project's signer policy; add negative regressions for noncritical variants.

2.29 — Leaf-certificate policy and source hygiene — 2026-10-10
-------------------------------------------------------------
- Require Basic Constraints CA:FALSE, digitalSignature Key Usage and codeSigning
  EKU. Add negative policy tests.
- Remove generated Python bytecode from the source and reject residual caches.

2.28 — macOS verification compatibility — 2026-10-10
--------------------------------------------------
- Verify published EFI files through the existing Jsign-compatible helper
  rather than directly invoking the unavailable Jsign 7.x verify command.
- Add a quality-gate check against reintroducing that bypass.

2.27 — Audit and version update — 2026-10-10
------------------------------------------
- Repeat runtime review, static analysis and host testing without establishing
  a new reproducible runtime defect; retain existing behavior.

2.26 — First-flush log preservation — 2026-10-08
----------------------------------------------
- Preserve the prior log during the first flush of a new session. Restore its
  bounded snapshot if replacement fails; retain new buffered data for retry.

2.25 — QueryMode side effects — 2026-10-08
----------------------------------------
- Keep the UI geometry cache consistent when defective firmware changes the
  active mode during QueryMode; preserve the device-error status.

2.24 — Partial console operations — 2026-10-08
--------------------------------------------
- Capture actual geometry after partial SetMode failures, skip firmware output
  for empty formatted strings, and guard console Mode pointers invalidated by
  nonconforming callbacks.

2.23 — Screenshot output bounds — 2026-10-08
------------------------------------------
- Reject insufficient SavedPath buffers before creating a screenshot, returning
  EFI_BUFFER_TOO_SMALL without leaving a successfully written but misreported BMP.

2.22 — False-success console mode changes — 2026-10-08
----------------------------------------------------
- Reject SetMode success that does not change the active mode; keep proven
  actual geometry and guard a Mode pointer invalidated by the callback.

2.21 — Console restoration failures — 2026-10-08
----------------------------------------------
- Avoid applying saved cursor coordinates when restoring the original text
  mode fails or falsely reports success; revalidate firmware Mode pointers.

2.20 — Redundant console restoration — 2026-10-08
-----------------------------------------------
- Avoid restoring console state already in place on the remembered-autoboot
  path, including unnecessary cursor queries and movement for color-only changes.

2.19 — Countdown redraws — 2026-10-08
------------------------------------
- Redraw the countdown only when its displayed value changes, avoiding extra
  firmware output after spurious key-event signals.

2.18 — Readable modes and transactional publication — 2026-10-08
--------------------------------------------------------------
- Keep an already-readable console mode instead of changing it redundantly.
- Stage Release output on the same filesystem with rollback, and lock builds
  before writing the canonical log.
- Sign and verify the dedicated smoke-test child before uploading it in CI.

2.17 — XML character-data preservation — 2026-10-05
--------------------------------------------------
- Ignore comments and processing instructions inside scalar values without
  inserting spaces into the resulting text.
- Reject invalid double-hyphen content in XML comments.

2.16 — USB-WWID policy and self-signature checks — 2026-10-04
----------------------------------------------------------
- Correct the previous USB-WWID interpretation: require 1..64 serial CHAR16
  values; a device without a serial uses the USB device-path subtype instead.
- Require cryptographic self-signature verification, rather than relying on
  matching subject/issuer names alone.
- Separate the selector's physical volume from configuration-write authority,
  retaining screenshots and volume priority when malformed settings are protected.

2.15 — USB-WWID classification — 2026-10-04
------------------------------------------
- Temporarily accepted an empty USB-WWID serial based on the vendored constructor.
  This interpretation was corrected in 2.16 after checking the UEFI requirement.

2.14 — Exact EKU and validity policy — 2026-10-04
-----------------------------------------------
- Decode the exact codeSigning OID and certificate validity from DER, rejecting
  subject-text false positives and certificates whose validity has not started.

2.13 — Independent Authenticode verifier — 2026-09-20
---------------------------------------------------
- Replace on-demand Java compilation with a Python/OpenSSL verifier for Jsign
  7.x extraction, checking PE/COFF digests, CMS/RSA signatures and certificate policy.
- Remove the javac/internal-JAR dependency and preserve fail-closed verification.

2.12 — Jsign 7.x verification route — 2026-09-20
----------------------------------------------
- Detect native verify support and introduce a compatible verification fallback
  for Jsign 7.5, whose CLI does not provide the newer verify command.
- The temporary Java fallback introduced here was replaced in 2.13.

2.11 — Pinned signer bootstrap — 2026-09-20
------------------------------------------
- Add optional download of the official Jsign 7.5 JAR to an external cache with
  a pinned SHA-256, HTTPS, staging and rejection of invalid cache/download content.

2.10 — Log rollover recovery — 2026-09-20
----------------------------------------
- Snapshot the bounded persistent log before rollover and restore its prior
  bytes after truncation/write/flush failures; invalidate uncertain file state.

2.09 — Transactional signing output — 2026-09-20
----------------------------------------------
- Publish the signed EFI, certificate and metadata together using staging,
  same-filesystem backups and rollback on error or cancellation.
- Reverify the published EFI before committing the transaction.

2.08 — Signing-path collision protection — 2026-09-20
----------------------------------------------------
- Canonicalize and reject aliases among signing input, signed output,
  certificate and metadata paths before generating cryptographic material.

2.07 — Ad-hoc PE/COFF signing — 2026-09-20
----------------------------------------
- Add verified ephemeral RSA-3072/SHA-256 signing with sbsign/sbverify or Jsign.
- Keep private keys temporary; publish the public certificate and provenance.
  Firmware trust remains a separate Secure Boot configuration requirement.

2.06 — Returning-image cleanup — 2026-09-15
------------------------------------------
- Probe UnloadImage after a successful StartImage return to clean up a
  potentially resident driver; distinguish already-unloaded applications from
  cleanup failures and stop safely when lifecycle state is compromised.

2.05 — Explicit modular arithmetic — 2026-09-15
----------------------------------------------
- Express SHA-256 modulo-2^32 arithmetic explicitly without sanitizer suppression.
- Correct intentional checksum/PRNG wraparound in test code and add a Clang
  integer-sanitizer mode to the quality gate.

2.04 — Python cache hygiene — 2026-09-15
---------------------------------------
- Purge __pycache__, .pyc and .pyo files before manifest verification and at
  teardown; reject residual caches in the quality gate.

2.03 — Unique remembered autoboot — 2026-09-15
--------------------------------------------
- Require a complete successful scan and exactly one global preferred match
  before remembered autoboot. Correct an undersized file-info mock in tests.

2.02 — SMBIOS compiler diagnostics — 2026-09-12
----------------------------------------------
- Initialize SMBIOS fallback state and retain validated version scalars without
  dereferencing an unavailable SMBIOS 3 pointer; add an optimized GCC warning test.

2.01 — Bounded hardware-card rendering — 2026-09-12
-------------------------------------------------
- Bound firmware-derived hardware strings by both source capacity and display
  width, preventing out-of-bounds reads on wide consoles.

2.00 — Direct-autoboot console path — 2026-09-12
----------------------------------------------
- Save original console state without mode probing; defer readable-mode
  selection until the UI is actually needed and avoid clearing an unseen menu.

1.99 — Compatible SMBIOS fallback — 2026-09-12
---------------------------------------------
- Require matching major/minor versions for fallback between SMBIOS 3.x and
  2.x tables, preventing mixed-schema results.

1.98 — UEFI character contract — 2026-09-12
------------------------------------------
- Reject supplementary Unicode and surrogate code units in configuration input
  and output to preserve the UEFI CHAR16/UCS-2 contract.

1.97 — Attribution coverage — 2026-09-12
---------------------------------------
- Extend project credits to host tests, the smoke child and notices, retaining
  upstream licenses and enforcing the required credit in the quality gate.

1.96 — Configuration directory creation — 2026-09-12
---------------------------------------------------
- Create \EFI before \EFI\BOOT when saving settings on a volume without that
  hierarchy, preserving staged writes and recovery behavior.

1.95 — Scoped compiler workaround and changelog — 2026-09-12
-----------------------------------------------------------
- Remove the global dead-store-elimination workaround while preserving the
  targeted GCC 10.2 workaround in BaseLib.
- Add a dedicated changelog and enforce synchronized source/document versions.
